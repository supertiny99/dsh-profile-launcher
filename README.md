# @supertiny99/dsh-profile-launcher

DSH（DeepSeek Harness）多 Profile 桌面版启动器与环境管理器：发现全部 profile 环境、独立 user-data 双开并存、新建 / 停止 / 删除生命周期管理，新建时可继承既有 profile 的模型配置。

本仓库为发布镜像（源码开发在 dsh-plugins 仓库），安装走 DSH 桌面版插件页 spec：

```text
@supertiny99/dsh-profile-launcher
```

文档见 npm 包内 README 或 [dsh-plugins 仓库](https://github.com/supertiny99/dsh-plugins/tree/main/profile-launcher)。
